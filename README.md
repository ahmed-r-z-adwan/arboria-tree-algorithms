# Arboria Tree Algorithms

Java console project with five data-structure missions focused on binary trees and Binary Search Trees.

## Missions

- Level-order traversal by levels
- Validate whether a binary tree is a BST
- Calculate range sum in a BST
- Find lowest common ancestor in a BST
- Reconstruct a tree from preorder and inorder traversals, then print postorder

## Concepts Practiced

- Binary Trees
- Binary Search Trees
- Recursion
- Queues
- HashMap
- Tree traversal algorithms

## Technologies

- Java
- Apache NetBeans
- Maven

## How To Run

Open the project in Apache NetBeans and run `Arboria.java`, or run the Maven project from the command line if Maven and Java are installed.
